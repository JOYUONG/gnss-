# main_cnn.py 代码说明与库版本

## 代码概述
该程序是一个基于卷积神经网络（CNN）的干扰源定位与功率估计系统，通过三阶段训练策略优化干扰源的位置和功率预测。程序采用了CNN降维+分支网络+BN处理+全连接网络的架构设计。

## 主要功能模块

### 1. 数据处理模块
- **InterferenceDataset**: 自定义数据集类，加载HDF5格式数据，将受干扰接收机信息转换为100×100的功率矩阵作为模型输入
- **generate_training_data**: 生成训练数据，每个样本包含200个接收机和1个干扰源
- **generate_data**: 生成测试数据，支持自定义参数

### 2. 模型架构
- **CNNReduction**: CNN特征提取网络，通过两次卷积和池化将100×100输入降维到3×10×10特征图
- **InterferenceModel**: 完整模型，包含两条处理分支：
  - A分支：用于位置预测，应用BN处理并通过全连接网络输出归一化坐标
  - B分支：用于功率预测，直接通过全连接网络输出功率值

### 3. 训练策略
采用三阶段训练方法：
1. **阶段1**：专注优化位置预测损失（MSE）
2. **阶段2**：专注优化功率预测损失（MAE）
3. **阶段3**：优化综合损失（位置损失×功率损失）

### 4. 定位与评估模块
- **NeuralLocalizer**: 干扰源定位器，加载训练好的模型并执行预测
- **calculate_paired_errors**: 计算定位误差，使用匈牙利算法进行最优匹配
- **calculate_paired_errors_pw**: 计算功率估计误差

### 5. 仿真与可视化
主程序部分执行10次仿真，生成测试数据，评估定位和功率估计性能，并绘制结果可视化图表

## 程序特点
1. **多阶段训练**：分别优化位置和功率预测，再联合优化
2. **分支网络结构**：对不同任务采用不同的处理路径
3. **数据预处理**：将接收机位置和功率信息转换为网格矩阵
4. **可视化分析**：提供定位结果和误差分布的可视化展示
5. **模块化设计**：各个功能模块相对独立，便于维护和扩展

## 执行流程
程序默认执行仿真测试而非训练（训练函数被注释），流程为：初始化定位器 → 生成测试数据 → 执行预测 → 计算误差 → 可视化结果 → 输出统计数据。
