# CNN+WCL 干扰源定位模型代码说明

## 1. 项目概述

本项目实现了一个基于卷积神经网络(CNN)与加权质心定位(WCL)融合的干扰源定位模型。该模型能够准确预测干扰源的位置和功率，达到10米级的位置预测精度和1dBm级的功率预测精度。

主要特点：
- 使用固定网格单元大小，自适应区域选择
- 区域过大时采用扩大网格单元大小的策略
- 结合CNN特征提取和WCL定位的优势
- 采用三阶段训练策略优化模型性能
- 包含自适应位置估计机制

## 2. 代码结构

### 2.1 核心类

#### InterferenceDataset
自定义数据集类，负责加载H5格式的训练数据，并进行数据预处理、特征提取和归一化。主要功能：
- 加载受干扰接收机数据、干扰源位置和功率信息
- 计算加权质心位置
- 自适应确定网格区域和大小
- 生成干扰功率矩阵
- 数据归一化处理

#### CNNReduction
CNN卷积降维模型，负责提取干扰功率矩阵的特征并降维。主要组件：
- 两层卷积层
- 两层最大池化层
- ReLU激活函数

#### InterferenceModel
完整的干扰源定位模型，包含以下主要部分：
- CNN降维模块
- Batch Normalization处理
- 位置预测分支（分支A）
- 功率预测分支（分支B）
- 置信度估计分支
- 自适应位置融合机制：X_final = α ⊙ X_CNN + (1 - α) ⊙ X_WCL

#### NeuralLocalizer
神经网络定位器类，封装了模型加载和预测功能，提供了便捷的接口进行干扰源定位。

### 2.2 主要函数

#### train_model
模型训练函数，实现了三阶段训练策略：
- 阶段1：优化位置预测（Loss1）
- 阶段2：优化功率预测（Loss2）
- 阶段3：综合优化位置和功率预测，并学习置信度

#### generate_training_data/generate_data
数据生成函数，用于创建训练和测试数据集。

#### calculate_paired_errors/calculate_paired_errors_pw
误差计算函数，用于评估模型定位和功率预测的准确性。

#### 主程序部分
初始化模型、生成测试数据、进行仿真实验、计算误差统计并可视化结果。

## 3. 技术实现细节

### 3.1 数据预处理

- **自适应区域选择**：根据受干扰接收机的分布自动确定感兴趣区域
- **动态归一化**：使用区域对角线长度作为归一化因子
- **网格自适应**：当区域过大时自动调整网格单元大小
- **数据增强**：通过扩展边界确保覆盖可能的干扰源位置

### 3.2 模型架构

- **卷积特征提取**：使用两层卷积网络提取干扰功率分布特征
- **双分支预测**：分别进行位置和功率预测
- **置信度学习**：自动学习CNN和WCL结果的置信度权重
- **自适应融合**：根据置信度动态融合CNN和WCL的定位结果

### 3.3 训练策略

- **分阶段训练**：先优化位置预测，再优化功率预测，最后综合优化
- **多目标损失函数**：L = 0.7*L_GNN + 0.3*L_adapt + 0.1*L_power
- **早停机制**：根据验证损失保存最佳模型
- **学习率策略**：使用AdamW优化器，设置适当的权重衰减

### 3.4 性能评估

- **位置误差**：欧几里得距离计算定位误差
- **功率误差**：绝对误差评估功率预测准确性
- **统计指标**：计算最小/最大/平均误差，以及RMSE
- **可视化分析**：绘制定位结果、误差分布和置信度分布

## 5. 使用说明

### 5.1 准备数据

训练数据存储在H5文件中，包含以下信息：
- 接收机位置和受干扰功率
- 干扰源真实位置和功率

可以使用`generate_training_data`函数生成训练数据，或`generate_data`函数生成测试数据。

### 5.2 训练模型

直接运行主程序将启动三阶段训练：
```python
python main_cnn4-3-11.py
```

训练好的模型权重将保存为`best_cnn2model4311_stage3.pth`。

### 5.3 干扰源定位

使用`NeuralLocalizer`类进行干扰源定位：
```python
locator = NeuralLocalizer()
# receivers为包含接收机位置和受干扰功率的数据
pred_jam_pos_final, pred_jam_pos_cnn, pred_jam_pos_wcl, alpha, pred_jam_pw = locator.predict(receivers)
```

返回值说明：
- `pred_jam_pos_final`：融合后的干扰源预测位置
- `pred_jam_pos_cnn`：CNN预测的干扰源位置
- `pred_jam_pos_wcl`：WCL计算的干扰源位置
- `alpha`：融合置信度权重
- `pred_jam_pw`：预测的干扰源功率

1. **多干扰源定位**：目前模型仅支持单干扰源定位，可以扩展为多干扰源场景
2. **鲁棒性增强**：添加噪声处理和异常值检测机制
3. **实时性优化**：模型压缩和推理加速
4. **迁移学习**：将模型应用于不同场景的干扰源定位
5. **集成学习**：结合多种定位方法提高精度
