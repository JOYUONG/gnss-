# main_cnn4-3-5.py 代码说明

## 1. 代码概述

`main_cnn4-3-5.py`是一个用于干扰源定位的深度学习模型实现，结合了CNN(卷积神经网络)和WCL(加权质心定位)技术，实现对单个干扰源的高精度定位和功率估计。

**主要功能与特点：**
- CNN与WCL自适应融合的干扰源定位方法
- 自适应网格和相对位置编码技术
- 分阶段训练策略，分别优化位置预测和功率预测
- 置信度学习机制，动态调整CNN和WCL的融合权重
- 提供完整的训练、预测和评估流程

**精度指标：**
- 位置精度：10米级
- 功率精度：1dBm级

## 3. 核心算法与技术亮点

### 3.1 自适应网格和相对位置编码

```python
X_max = np.max(affected_receivers['x'])
X_min = np.min(affected_receivers['x'])
Y_max = np.max(affected_receivers['y'])
Y_min = np.min(affected_receivers['y'])
X_range=X_max-X_min
Y_range=Y_max-Y_min
X_center=(X_max+X_min)/2
Y_center=(Y_max+Y_min)/2
Lx=X_range/100
Ly=Y_range/100
L=np.maximum(Lx,Ly)
```

**技术优势：** 根据受干扰接收机的分布动态调整网格大小和中心位置，使模型能够适应不同场景下的干扰分布，提高定位精度。

### 3.2 置信度学习与自适应融合

```python
# 自适应位置估计: X_final = α ⊙ X_CNN + (1 - α) ⊙ X_WCL
pos_pred_final = alpha * pos_pred_cnn + (1 - alpha) * wcl_pos
```

**创新点：**
- 模型自动学习置信度α，动态平衡CNN预测和WCL结果
- 在复杂环境中，自动增加更可靠方法的权重
- 实现位置维度级别的自适应融合，x和y方向可以有不同的融合权重

### 3.3 分阶段训练策略

**训练流程：**
1. **阶段1**：专注优化位置预测，使用L_CAGE损失函数
2. **阶段2**：专注优化功率预测，使用绝对误差损失
3. **阶段3**：综合优化所有任务，调整损失权重，同时学习置信度

**优势：** 分阶段训练使模型能够先掌握基础任务，再逐步学习更复杂的关系，提高整体性能和稳定性。

## 5. 程序执行流程

1. **数据准备**：通过`generate_training_data`生成训练数据，或从HDF5文件加载
2. **模型训练**：执行`train_model()`函数，分三阶段训练模型
   - 阶段1：优化位置预测
   - 阶段2：优化功率预测
   - 阶段3：综合训练，学习置信度
3. **模型预测**：使用`NeuralLocalizer`类加载训练好的模型进行推理
4. **性能评估**：计算定位误差、功率估计误差，生成统计结果和可视化图表
5. **结果分析**：通过误差分布直方图和置信度分布图表，分析模型性能
